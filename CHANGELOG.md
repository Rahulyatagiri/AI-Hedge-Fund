# Changelog

All notable changes and enhancements to this project will be documented in this file.

## [1.0.0] - 2025-11-18

### Added
- **Custom Configuration System**: Introduced `config.yaml` for centralized system configuration
- **Configuration Loader Utility**: New `config_loader.py` module for managing YAML-based configuration
- **Setup Script**: Automated setup script (`setup.sh`) for easy installation and environment setup
- **Contributing Guidelines**: Comprehensive `CONTRIBUTING.md` with detailed contribution instructions
- **Enhanced Documentation**: Updated README with improved structure and custom branding
- **Risk Management Presets**: Predefined risk management parameters in configuration
- **Agent Weight System**: Configurable weights for different trading agents
- **Custom Backtesting Parameters**: Configurable initial capital, commission rates, and slippage

### Changed
- **Project Name**: Rebranded to "AI-Powered Quantitative Trading System"
- **Package Name**: Updated from `ai-hedge-fund` to `ai-quant-trading-system`
- **Version**: Bumped to 1.0.0 to reflect major enhancements
- **Repository Information**: Updated all references to point to Rahulyatagiri/AI-Hedge-Fund
- **Installation Process**: Streamlined with automated setup script
- **README Structure**: Reorganized with "Key Features & Enhancements" section

### Technical Improvements
- Added PyYAML dependency for configuration management
- Implemented flexible configuration loading system
- Enhanced project metadata in `pyproject.toml`
- Created modular architecture for easier extensibility

### Documentation
- Updated all GitHub repository links
- Added detailed contribution guidelines
- Enhanced installation instructions with quick setup option
- Documented configuration system usage

---

## Project Origin

This project is built upon the foundation of the ai-hedge-fund project, with significant enhancements and customizations to create a unique quantitative trading system. The original concept has been extended with:

- Advanced configuration management
- Enhanced modularity and extensibility
- Improved documentation and setup process
- Custom utility modules
- Streamlined contribution workflow
